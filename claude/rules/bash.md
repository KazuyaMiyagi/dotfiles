# Bash / シェルスクリプト規約

## ファイル変更時のチェック

シェルスクリプト（`.sh`/`.bash` や shebang が bash/sh のファイル）を変更した場合、コミット前に以下を実行する。

```bash
shellcheck <file>                             # 静的解析
shfmt -d -ln bash -i 4 -bn -ci -sr -kp <file> # 整形差分の確認
```

- `shellcheck` の指摘（未クォート変数 `SC2086`、`[ ]` vs `[[ ]]` など）は修正してからコミットする
- `shfmt -d` で差分が出たら `shfmt -w -ln bash -i 4 -bn -ci -sr -kp <file>` で整形する。
  efm-langserver の設定値は
  `--indent 4 --binary-next-line --case-indent --space-redirects --keep-padding`。
  フラグを揃えてあるので、エディタ保存時の整形と CLI の結果が一致する
- 変数は基本ダブルクォートで囲む。
  `set -e -u -o pipefail` を冒頭に置く。
  オプションを 1 つずつ書くと、`-o` が `pipefail` を引数に取ることが読み取りやすい
  途中のコマンドが失敗しても最後まで続けたいスクリプトは、`-e` だけを外して `set -u -o pipefail` とする
- shebang は `#!` とパスの間にスペースを入れて `#! /usr/bin/env bash` と書く
- 条件式は `[ ]` ではなく `[[ ]]` で書く
- 変数は `${var}` と波括弧を付けて参照する。
  位置パラメータも `${1}`・`"${@}"`・`${#}` と書く
- 代入の右辺のコマンド置換も `x="$(command)"` とダブルクォートで囲む。
  算術式 `$((...))` は囲まない
- 本体の関数と `usage` 以外の関数は `function __name()` と頭に `__` を付ける
- `usage` の中のコマンド名は `local COMMAND=...` と `readonly COMMAND` で宣言する
- 配列は `"${arr[@]}"` とダブルクォートで囲んで展開する
- ハイフン区切りはコマンド（ファイル名）だけに使い、関数名と変数名はアンダースコア区切りにする。
  コマンドと同じ処理をする関数も `send_text` のようにアンダースコアにする
- エラーは `echo "Error: ..." >&2` と書いて標準エラーに出す
- エスケープ文字は `\033` ではなく `\e` と書く
- `usage` は `cat <<- HEREDOC` で書き、本文をタブで字下げする
- 出力を捨てるときは `> /dev/null 2>&1` ではなく `&> /dev/null` と書く
- `[[ ]]` の中の文字列の比較は `=` ではなく `==` で書く
- 複数の条件は `[[ a ]] && [[ b ]]` と分けず、`[[ a && b ]]` と 1 つの `[[ ]]` にまとめる
- `printf` の書式は、変数を展開しないなら `'...'` とシングルクォートで囲む
- コメントは日本語で書く
- 画面に出すメッセージと `usage` は英語で書く。
  `wareki` の元号のように、出力そのものが日本語のものは除く
- 関数の外に置く引数や設定値は大文字の変数にして、次の行で `readonly` を付ける。
  関数の中の変数は `local` で宣言し、小文字にする
- 処理はコマンド名をアンダースコア区切りにした本体の関数（`send_text` など）に書き、ファイルの最後で呼ぶ。
  関数の外には `set`・定数・関数の定義・引数の受け取りと、本体の関数の呼び出しだけを置く
- `set` の次に、何をするスクリプトかを 1〜2 行のコメントで書く
- 引数を取るスクリプトには `usage` を用意する。
  引数が足りないときやおかしいときは `usage >&2` のあとに `exit 1` する
- コマンドの出力を 1 行ずつ回すときは `for x in $(command)` ではなく、
  `while IFS= read -r -u 3 x; do ... done 3< <(command)` と書く。
  ループの中のコマンドが標準入力を読んでも一覧を食わないよう、ファイル記述子 3 から読む
- 数を数えるループは `for ((i = 1; i <= n; i++))` と書く
